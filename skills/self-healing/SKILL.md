# Skill: self-healing

## Description
Active runtime recovery — diagnose, patch, verify, file the verified fix when a command, test, helper, env, or external service fails mid-task.

## Workflow
1. Diagnose failure.
2. Propose patch.
3. Verify patch.
4. File fix in .learnings/HEALS.md.
