## 2. METRIC FORMULAS

- **Customer Acquisition Cost (CAC)**: $\frac{\text{Total Marketing \& Sales Expense}}{\text{New Clients Acquired}}$
- **Lifetime Value (LTV)**: $\text{Average Project Value} \times \text{Repeat Purchase Frequency}$
- **3D Render Frame Rate (FPS)**: $\frac{\text{Total Rendered Frames}}{\text{Time Window in Seconds}}$
- **Milestone Variance**: $\text{Actual Delivery Date} - \text{Baseline Milestone Target Date}$
