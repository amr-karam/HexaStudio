# 📁 CLIENT PORTAL FILE MANAGEMENT SPECIFICATIONS

**Version:** 1.0.0 | **Scope:** Deliverable Storage | **Standard:** Secure MinIO S3 Integration

---

## 1. OVERVIEW & FEATURES

The Client Portal File Management module (`/portal/projects/:id/files`) provides secure access to final architectural renders, 3D model packages, blueprints, and contract documentation hosted on MinIO object storage.

---

## 2. KEY CAPABILITIES

- **Presigned URLs**: Time-limited signed URLs generated by NestJS BFF (`GET /api/v1/portal/files/:id/download`).
- **Drag-and-Drop Uploads**: Clients can upload feedback attachments directly to project asset buckets.
- **Role-Based Access**: Access restricted strictly to authenticated `res.partner` users linked to the Odoo project.
