# 📖 CONTEXT: Domain Dictionary

- **BFF**: Backend-For-Frontend microservice (`apps/backend`).
- **Client Digital HQ**: The Client Portal (`/portal`) for approvals, invoices, and deliverables.
- **5-Second Clarity Grid**: Portal dashboard overview presenting instant project health metrics.
- **Client Island**: A Client Component wrapping WebGL canvas components dynamically imported with `ssr: false`.
- **Odoo Sync**: Synchronizing Odoo `crm.lead` and `account.move` data via NestJS `OdooApiService`.
