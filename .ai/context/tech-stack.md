# 💻 CONTEXT: Monorepo Tech Stack Summary

- **Frontend**: Next.js 16 (App Router), TypeScript 5.8, TailwindCSS 4, Three.js, R3F, Framer Motion, GSAP.
- **Backend**: NestJS 11, Socket.io, REST (Swagger), TypeORM / Prisma, JWT.
- **CMS**: Strapi 5 (Headless).
- **ERP**: Odoo 17 (JSON-RPC client).
- **Databases**: PostgreSQL 16, Redis 7, Qdrant Vector DB.
- **Proxy**: Traefik v3 + Cloudflared.
- **DevOps**: GitLab CE, Docker Compose.
