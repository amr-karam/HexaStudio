# 🚨 WORKFLOW: Hotfix Protocol

```text
1. Declare Critical Incident (High/Critical Risk)
   ↓
2. Branch from Latest Release Tag (`hotfix/vX.Y.Z-description`)
   ↓
3. Apply Minimal Surgical Repair & Unit Test
   ↓
4. Fast-Track Peer Review & CI Gate Execution
   ↓
5. Direct Deployment & Post-Incident Root Cause Analysis (RCA)
```
